# Yuliana Calzados

## Descripción del proyecto

Yuliana Calzados es un sistema web orientado a la venta de calzado femenino. Su objetivo es facilitar la gestión comercial y el proceso de compra mediante una aplicación web.

## Tecnologías utilizadas

- Java
- Spring Boot
- Spring MVC y Thymeleaf
- Spring Data JPA / Hibernate
- MySQL
- Maven
- HTML, CSS y JavaScript
- Bootstrap

## Funcionalidades

- Visualización de productos de calzado.
- Carrito de compras.
- Proceso de compra.
- Registro de ventas.
- Actualización del stock de productos.
- Gestión de productos y otras funcionalidades según los módulos implementados.

## Requisitos previos

- JDK compatible con el proyecto.
- MySQL Server.
- Git.
- Visual Studio Code u otro IDE compatible con Java.

## Instalación y ejecución

1. Clonar el repositorio desde GitHub.
2. Crear la base de datos `yuliana_calzados` en MySQL.
3. Configurar las credenciales de MySQL en `src/main/resources/application.properties`.
4. Abrir una terminal en la carpeta del proyecto.
5. Ejecutar la aplicación en Windows:

   ```powershell
   .\mvnw.cmd spring-boot:run
   ```

6. Abrir el navegador y acceder a `http://localhost:8080/`.

## Control de versiones

El proyecto utiliza Git para registrar los cambios mediante commits y GitHub para alojar el repositorio remoto y mantener un historial de versiones.
